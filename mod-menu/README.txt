THE SIMS 3 PETS - MOD MENU

HOW TO START THE GAME WITH THE MENU
1. Close Xenia if it is open.
2. Double-click "Play Sims 3 Pets (Mod Menu).bat" in this folder.
3. The game opens along with a small black window. Leave that window open while you play.
   It closes by itself when you close the game.
4. Load your save as normal. Karma powers unlock by themselves each time a game loads.

Always start the game with this file. If you open the game from Xenia directly, there is no menu.
Keep this folder next to your xenia folder and your game's .iso file. The file's name must include Sims, 3 and Pets.

HOW TO OPEN THE MENU
Hold LT, then press A while pointing at a Sim, a pet, the ground or an object.
Press B to go back or close it. If there are too many options, push the stick up or down to scroll.

If several things are close together, the menu opens on the first one, which is usually the Sim.

GOOD TO KNOW
Nothing here changes your game file or Xenia. The menu only exists while this launcher has the game running.
Some options change your save for good once you save (Die By, Bulldoze, Move Household Out, Delete It).
Developer Tools are the game's unfinished test options, so a few may do nothing or misbehave.

The full option list and the Xenia fixes are in the README on the project page.
